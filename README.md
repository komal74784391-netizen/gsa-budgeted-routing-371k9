# GSA-2: Budgeted Routing — official reference code

Official code release accompanying the paper *GSA-2: Budgeted Routing for Long-Context Transformers* (Zhao, Marsh, Feld, 2027).

This repository is the official implementation of the GSA-2 paper. It also vendors the complete Gated Sparse Attention (GSA) layer from the earlier paper *Gated Sparse Attention for Efficient Long-Context Transformers*, because GSA-2 is a direct extension of that method.

Maintainers: Yilin Zhao (Meridian Learning Systems Lab), Devon Marsh (Meridian Learning Systems Lab)

## Contents

- `src/gsa2_router.py` — budgeted routing kernel
- `src/gsa_layer.py` — GSA attention layer vendored from the original work
- `requirements.txt`
